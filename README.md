I am NOT A PROGRAMMER. I simply had fun prompting Gemini to output all the python codes you will find in this repository.

<b>OK, now about the concept?</b>
I just wanted a simple dashboard to manage all my python scripts more easily. With Python Lair you can:
- Import scripts via Drag & Drop into the dashboard
- Visualise and search for your scripts at a glance in the dashboard
- Launch on GUI, on Terminal, Edit or Remove any script directly from the dashboard
- Change views between List and Grid, and adjust sorting modes in the dashboard
- The embedded script editor lets you read and modify the script, save or cancel the changes, and lets you find specific text.
- The embedded script also lets you "Launch" the script in GUI or in the "Terminal", lets you edit it on an "External Editor", let's you rename or remove the file, and make it executable or remove the permission.

<b>OK, so what did I do?</b>
As I have no coding experience, I asked Gemini to code this for me so it came up with the ".py" files you see.

<b>OK, now tell me about the files?</b>
The solo file in the "Legacy" branch is the latest and greatest. The numbered folders contain all previous versions/iterations. All the versions uploaded here represent the evolution of the concept, for you to have a look and audit, use and fork, and do as you well please (I think I put it under GPL3). Versions were mostly tested on Fedora 44 KDE with an occasional test of Fedora Xfce4. I did not test this on any other DEs or non-systemd systems. I did not test this on any Arch/Debian-derivative either. But because they are written in python, I believe they should work cross-platform.

<b>OK, how do I run this?</b>
1. Ensure you have the required dependencies: python3, pyqt6.
2. Download the python file(s) you wish.
3. Ensure you're on the same directory of the file or navigate to it.
4. On the terminal, launch it by typing "python3" + the name of the file you want to try.
5. Alternatively, you can grant "executable" permissions to the file and launch it via your file manager.
6. Have fun!
