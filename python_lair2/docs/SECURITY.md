# Security Policy

## Supported versions

| Version | Support |
| --- | --- |
| 2.0.x | Security and critical reliability fixes |
| Earlier internal builds | Not supported |

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability in a public issue.
Contact the maintainer privately using the contact information on the GitHub
profile associated with this repository.

Include the affected version, runtime mode, distribution, reproduction steps,
potential impact, and any relevant logs or proof of concept. Please allow a
reasonable period for investigation before public disclosure.

Python Lair launches user-controlled Python scripts. Reports should distinguish
between expected execution of a selected script and vulnerabilities that allow
unexpected code execution, path escape, privilege changes, or data loss.
